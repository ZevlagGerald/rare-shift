## One sentence

**RARE//SHIFT is a phase-shifting survival action roguelite where your ownership-verified Rare Friend's canonical animation becomes the signature weapon geometry and the battlefield law that decides which threats are corporeal.**

## What did you build?

RARE//SHIFT turns the selected Rare Friend into a mechanical input rather than a cosmetic skin. Its canonical animation drives DELTA weapon geometry, while the player survives an escalating arena by moving, auto-firing, drafting weapon upgrades, and using SHIFT to flip the battlefield between Phase A and Phase B.

A-aligned threats are corporeal in A and ghosted in B; B-aligned threats do the opposite; COMMON threats remain dangerous in both. SHIFT therefore rewrites target authority, phase-sensitive weapon behavior, and positioning decisions in real time.

The submission build includes five distinct weapon families with qualified Rank I→V behavior:

- **DELTA BURST** — canonical Friend geometry and phase-echo progression;
- **VECTOR NEEDLE** — penetration, priority tracing, post-SHIFT transfer, vector lock;
- **ORBIT NODES** — multi-node coverage, phase shear, synchronized ring;
- **ECHO MINE** — leave/return phase memory, faster recall, deep-memory collapse;
- **SIGNAL ARC** — deterministic relay graphs, resonant COMMON extension, chain control.

Exactly four active weapon slots are available and DELTA is mandatory, keeping the selected Friend's identity at the center of every run.

## How does it use Rare Friends?

The player connects through FriendSDK, selects an owned hardwired Generations NFT, and plays as that Friend using the SDK's ownership-gated identity/runtime. RARE//SHIFT reads the Friend's canonical animation data and uses its frame differences to define the DELTA combat geometry and the game's A/B phase language.

> **Your Friend is not a skin. Its animation is the rules.**

## How to play

- `WASD` / arrow keys — move;
- `Space` — SHIFT Phase A ↔ B;
- touch controls — movement and SHIFT on supported narrow screens;
- click/tap draft cards — choose upgrades;
- weapons auto-fire.

Survive, read the current phase, reposition around corporeal threats, SHIFT at useful moments, collect XP, and shape a four-weapon build through deterministic level-up drafts.

## Known limitations

- FriendSDK session state is not a persistent save system; reloading begins a new session.
- Protocol/evolution runtime, elite/boss pacing, final tournament-scale progression, and final audio/presentation polish are post-submission work.
- The Rank-V ECHO `2 damaging hits / target / rolling 250 ms` safety ledger is fully deterministic-tested. Direct browser observation of a third hit being suppressed is deferred until a legitimate higher-HP threat exists; current production enemies die before that sequence can be demonstrated honestly.
- The submitted MVP does not claim live Token Activity or live RF burning/spending.

## Local setup

Node.js 22+ is required.

```sh
mkdir -p vendor
curl -L -o vendor/rarefriends-friendsdk-0.1.2.tgz \
  https://github.com/spokesz/friendsdk/releases/download/v0.1.2/rarefriends-friendsdk-0.1.2.tgz
npm install --no-audit --no-fund
npm run dev
```

The official FriendSDK v0.1.2 archive is SHA-256 verified in CI.
