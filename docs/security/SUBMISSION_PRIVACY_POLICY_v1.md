## Private by default

The following must not be committed to this repository or included in public submission materials unless the owner explicitly authorizes disclosure for a documented competition requirement:

- personal email addresses;
- legal-name records beyond the approved public builder identity;
- home address or phone number;
- wallet private keys, seed/recovery phrases, keystore files or signing material;
- API keys, tokens, passwords, RPC credentials or environment secrets;
- private local paths or machine-specific credentials;
- identity documents or payout/KYC documents.

A public blockchain wallet address may be disclosed only if the competition organizer specifically requires it for eligibility, verification or payout. It is otherwise omitted from the public README and submission PR.
